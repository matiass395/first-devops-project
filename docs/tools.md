# Zainstalowane narzędzia

| Narzędzie | Opis |
|-----------|------|
| git | System kontroli wersji – historia zmian, gałęzie, praca zespołowa |
| curl | Wysyłanie zapytań HTTP z terminala – testowanie API, health checki |
| wget | Pobieranie plików z internetu, z obsługą wznawiania pobierania |
| unzip | Rozpakowywanie archiwów .zip |
| htop | Interaktywny monitor procesów, CPU i pamięci RAM |
| tree | Wyświetlanie struktury katalogów w formie drzewa |
| jq | Przetwarzanie i filtrowanie danych JSON w terminalu |
| zsh + Oh My Zsh | Rozbudowana powłoka z podpowiedziami, motywami i wtyczkami |
| docker | Konteneryzacja – uruchamianie aplikacji w izolowanych środowiskach |
